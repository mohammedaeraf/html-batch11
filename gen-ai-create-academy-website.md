# Project - Future Leaders Academy Website

## Intro

This is an excellent real-world project because students learn both **Bootstrap** and **AI-assisted development** together.

The idea is to **never ask ChatGPT to generate the whole website at once**. Instead, build it step-by-step like a professional developer. Students also learn how to improve AI-generated code.



**Technology**

* HTML5
* Bootstrap 5
* Bootstrap Icons
* Custom CSS
* Responsive Design

**Sections**

* Navbar
* Hero/Home
* About
* Courses
* Faculty
* Testimonials
* Contact
* Footer

---

# Prompt 1 — Create the Basic Website Structure

```
You are an expert Frontend Web Developer.

Create a responsive HTML website for an IT Training Institute named "Future Leaders Academy" using Bootstrap 5.

Requirements:

• HTML5 structure
• Bootstrap 5 CDN
• Bootstrap Icons CDN
• Separate custom CSS file
• Responsive navbar
• Smooth scrolling navigation
• Navigation items:
  - Home
  - About
  - Courses
  - Our Faculty
  - Testimonials
  - Contact

Create empty Bootstrap sections with proper IDs for every menu.

Do not add content yet.
Only generate the website skeleton with semantic HTML.
```
