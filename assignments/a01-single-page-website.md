# Assignment: Build a Single-Page Website

## Objective

Design and develop a **single-page website** using **HTML5** and **Bootstrap 5**. The purpose of this assignment is to practice semantic HTML elements, internal navigation, Bootstrap utility classes, forms, images, and cards while creating a clean and attractive webpage.

---

# Theme

Create a website for **Future Leaders Academy**, an institute that offers IT and professional skill development courses.

You may use free images from websites such as Unsplash or Pexels.

---

# Requirements

Your website must contain the following sections:

### 1. Header

* Website title/logo
* Navigation menu using the `<nav>` element
* Navigation links should use **internal links** (`href="#section-id"`)

---

### 2. Hero Section

* Large background image
* Website title
* Short description
* "Explore Courses" button that links to the Courses section

---

### 3. About Us

Use semantic elements:

* `<section>`
* `<article>`

Include:

* Brief introduction about the academy
* One relevant image

---

### 4. Courses

Display at least **4 Bootstrap Cards** for different courses.

Each card should contain:

* Course image
* Course title
* Short description
* "Learn More" button

Example courses:

* Web Design
* Python Programming
* Advanced Excel
* Digital Marketing

---

### 5. Why Choose Us?

Display points such as:

* Experienced Trainers
* Practical Learning
* Industry Projects
* Certificate on Completion

---

### 6. Gallery

Display at least **4 images** related to education or technology.

---

### 7. Contact Us

Create a contact form containing:

* Full Name
* Email Address
* Phone Number
* Message (Textarea)
* Submit Button

---

### 8. Footer

Include:

* Copyright
* Quick Links
* "Back to Top" internal link

---

# Semantic Elements to Use

Use the following HTML5 semantic elements wherever appropriate:

* `<header>`
* `<nav>`
* `<section>`
* `<article>`
* `<footer>`

---

# Bootstrap Classes to Use

Use Bootstrap utility classes for styling such as:

### Text

* `text-center`
* `text-primary`
* `text-secondary`
* `fw-bold`

### Background

* `bg-light`
* `bg-white`
* `bg-primary`
* `text-white`

### Spacing

* `m-*`
* `mt-*`
* `mb-*`
* `p-*`
* `pt-*`
* `pb-*`

### Borders

* `border`
* `rounded`

### Buttons

* `btn`
* `btn-primary`
* `btn-outline-primary`

### Cards

* Bootstrap Card component

### Forms

* Bootstrap Form controls
* Bootstrap Buttons

---

# Submission Guidelines

Submit the following files:

* `index.html`
* `images` folder containing all images used

Ensure that:

* All navigation links work correctly.
* Images load properly.
* The page is well-organized and easy to read.
* HTML code is properly indented.
* Bootstrap is linked using a CDN.
